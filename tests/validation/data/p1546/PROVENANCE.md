# Provenance — P.1546-6 official validation data

`profiles/*.csv` (24 SG3 measurement/test profiles) and
`combined_results_reference.csv` are the official ITU-R WP3K validation
examples for Recommendation P.1546-6 (validation set v6.2, published on the
ITU-R SG3 "Software, Data and Validation" page), mirrored via
https://github.com/eeveetza/Py1546 tests/ (file-verified against the official
ITU zip during the 2026-07-09 de-risk). Reference values are the WP3K-approved
implementation's outputs for these inputs. The measurement paths are civilian
ITU SG3 broadcast-research data.
